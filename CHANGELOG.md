# Changelog

All notable changes across components, aggregated per release. Per-package
detail lives in `packages/<name>/CHANGELOG.md`.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
Entries are written by [multicz](https://github.com/goabonga/multicz) at
release time — do not edit them by hand.
